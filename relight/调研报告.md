# 图片重打光（Relighting）方案调研

> 调研日期：2026-07-22  
> 目标：为 `input image + relight instruction + output image` 训练数据生产筛选可用的开源模型、工作流与托管 API。

## 1. 业务中的“重打光”

重打光应保持场景几何、人物身份、动作、物体、构图和相机视角不变，只改变光源方向、强度、色温、软硬、高光、阴影、反射光和环境光。单纯调亮度、色温或滤镜不等于完整的重打光。

现有方法主要分为：

1. **生成式重打光**：直接从原图、文字、光照参考或 HDRI 生成新图。接入简单、效果有表现力，但可能重绘人脸、纹理或背景。
2. **逆渲染/PBR 重打光**：估计深度、法线、反照率和材质，再在可控灯光下渲染。物理控制更强，但单图几何/材质估计错误会传播到结果，工程也更复杂。

## 2. 优先候选

### Freepik Relight API

- 支持 Prompt、光照参考图、Light Map、光照迁移强度、`preserve_details` 和 `change_background=false`。
- 优势：控制项直接对应“只改光”，可关闭背景替换，可通过参考图迁移光照。
- 风险：细节保持和输出尺寸需样片实测，仍可能出现纹理重绘。
- 官方文档：<https://docs.comfy.org/api-reference/freepik/relight-an-image>

### fal.ai Relighting Preset

- 提供 natural、studio、golden hour、blue hour、soft/hard、front/side/back/rim light、sunset、neon、moonlight 等预设。
- 标注可商业使用，调研时页面报价约每张 0.04 美元，提供 4K 输出。
- 优势：接口最简单，适合快速批量基线。
- 风险：只有预设类别，精确方向/强度可控性有限，且只支持部分比例。
- 官方页面：<https://fal.ai/models/fal-ai/image-apps-v2/relighting>

### fal.ai IC-Light V2

- 支持 Prompt、Mask、左/右/上/下光照初始条件、自定义尺寸、Seed 和高分辨率修复。
- 优势：专用重打光模型，文字氛围和光源方向都可控。
- 风险：接口同时定位于重打光和背景编辑，高去噪强度可能重绘主体或背景。
- 官方文档：<https://fal.ai/models/fal-ai/iclight-v2/api>

## 3. 本地和专业方案

### IC-Light V1 / ComfyUI

- 官方包含文字条件和前景+背景条件模型，可控左/右/上/下光照偏好。
- 优势：可本地运行、固定 Seed，大规模时可降低逐张 API 成本；ComfyUI 已有成熟节点。
- 风险：基于 SD1.5，高分辨率细节和身份保持弱于新模型。代码、权重和前景分割器需分层核对许可；官方特别提醒 BRIA RMBG 1.4 为非商业使用。
- 官方仓库：<https://github.com/lllyasviel/IC-Light>
- 权重：<https://huggingface.co/lllyasviel/ic-light>
- ComfyUI 节点：<https://github.com/kijai/ComfyUI-IC-Light>

### Beeble / SwitchLight 3.0

- 通过 Normal、Base Color、Metallic、Roughness、Specular 等 PBR Pass 实现专业重打光，支持 Nuke、Blender 和 Unreal 工作流。
- 优势：物理光照控制和 VFX 生产能力强。
- 风险：更偏人工 VFX 工作流；调研时 SwitchLight 尚未开放公开 API，只有 SwitchX 可用 API。
- 官方文档：<https://docs.beeble.ai/>
- API 状态：<https://developer.beeble.ai/pricing>

## 4. 通用编辑与研究方案

### FLUX.2

- 支持单图文字编辑、光照/时间变化和最高 4MP 输出。
- 优势：内容保持与 Prompt 理解能力强，API 成熟。
- 风险：不是物理重打光模型；“黄昏/夜晚”指令可能同时改变天空、环境和物体。
- 官方文档：<https://docs.bfl.ai/flux_2/flux2_image_editing>

### Neural Gaffer

- 单图+目标 HDR 环境贴图的通用物体重打光研究模型。
- 适合产品、雕塑和单独物体，复杂全场景与人群并非最优输入。
- 项目页：<https://neural-gaffer.github.io/>

### Lite2Relight

- 面向头像/人脸的 3D 感知重打光，使用 HDRI 控制头部、头发、眼睛和表情上的光照。
- 专用人像能力强，但不适合通用场景。
- 项目页：<https://vcai.mpi-inf.mpg.de/projects/Lite2Relight/>

### PIXLRelight

- 2026 年研究方案：用 Depth Anything 3 恢复几何、估计材质，在 Blender Cycles 定义 PBR 灯光，再用神经渲染器产生最终重打光。
- 物理控制和细节保持方向与业务匹配，但完整链路包含几何/材质恢复和 Blender 渲染，集成成本高。
- 项目页：<https://mlfarinha.github.io/pixl-relight/>

## 5. 建议

1. 当前保底链路使用已有 Qwen VL + ToAPIs `gpt-image-2`，先证明选图、指令和生图能串联。
2. 后续用同一小批原图横向测试 Freepik Relight、fal Relighting Preset 和 fal IC-Light V2。
3. 横评不只看“好不好看”，而要分别记录主体/背景保持、光源方向、阴影合理性、是否只是滤镜、分辨率、速度和单张成本。
4. 如 API 方案达标且进入大规模生产，再评估本地 IC-Light 或专用模型以降低成本。
